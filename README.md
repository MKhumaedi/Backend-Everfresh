# Backend Everfresh

> ⚠️ **Status: Dalam Tahap Pengembangan (Under Development)**

Repository backend untuk sistem Everfresh yang dibangun menggunakan Node.js, PostgreSQL, dan Prisma.

## 🛠️ Tech Stack
* **Runtime:** Node.js
* **Database & ORM:** PostgreSQL & Prisma

## 📌 Catatan
Backend ini masih dalam tahap pengembangan aktif untuk mendukung fitur-fitur pada aplikasi Everfresh.
